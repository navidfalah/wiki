# 13 — Configuration

All configuration files and environment variables.

## `.env` (repo root)

Copy from `.env.example`:

```bash
cp .env.example .env
```

```env
OPENAI_API_KEY=
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-4o-mini
```

| Variable | Required | Default | Used by |
|----------|----------|---------|---------|
| `OPENAI_API_KEY` | No | empty | `llm_client.py` — enables LLM mode |
| `OPENAI_BASE_URL` | No | OpenAI v1 URL | Compatible APIs |
| `OPENAI_MODEL` | No | `gpt-4o-mini` | Chat completions, image captioning |
| `OPENAI_EMBEDDING_MODEL` | No | `text-embedding-3-small` | Hybrid retrieval embeddings |
| `OPENAI_TRANSCRIPTION_MODEL` | No | `whisper-1` | Audio transcription (`media_ingest.build_audio_chunk()`) |

Loaded via `python-dotenv` when `llm_client` module imports.

**Gitignore:** `.env` should never be committed.

## `wiki-app/docusaurus.config.js`

| Setting | Purpose |
|---------|---------|
| `title`, `tagline` | Site branding |
| `url`, `baseUrl` | GitHub Pages vs local paths |
| `organizationName`, `projectName` | Docusaurus deploy metadata |
| `customFields.wikiApiUrl` | Dashboard API base URL |
| `themeConfig.navbar.items` | Top navigation |
| `presets.classic.docs` | Docs plugin — path `docs`, sidebar `wikiSidebar` |
| `onBrokenLinks` | `'warn'` |
| `markdown.hooks.onBrokenMarkdownLinks` | `'warn'` |

### Override API URL

```bash
WIKI_API_URL=http://staging.example.com:8000 npm start
```

## `wiki-app/sidebars.js`

Defines `wikiSidebar` for compiled docs. Typically autogenerated or minimal — compiler pages appear as filesystem docs under `docs/`.

## `wiki-app/tailwind.config.js`

- Content paths: `src/**/*.{js,jsx}`
- `corePlugins.preflight: false` — coexist with Docusaurus

## GitHub Actions env (CI)

From `.github/workflows/wiki-build.yml`:

```yaml
GITHUB_PAGES: "true"
GITHUB_ORG: ${{ github.repository_owner }}
GITHUB_REPO: ${{ github.event.repository.name }}
```

Required repo secret:

- `OPENAI_API_KEY` — the compiler is LLM-only (see [08-llm-and-heuristics.md](./08-llm-and-heuristics.md)); without this secret set, `python compiler/main.py` fails immediately and the workflow build step fails.
