# Embedded Systems

## Overview
Embedded systems, in the context of this project, refer to specialized computer systems designed to perform dedicated functions within a larger mechanical or electrical system. A primary application discussed is the development of open [Sensors](./Sensors.md) for gardeners, with a strong emphasis on user [Data Ownership](./Data Ownership.md).

## Key Details
*   **Purpose:** To create open [Sensor](./Sensors.md) solutions, particularly for gardening applications, ensuring users retain ownership of their collected data.
*   **Product Example:** The [Nova Widget](./Nova Widget.md) is an example of an embedded system under development. It functions as a soil moisture and temperature [Sensor](./Sensors.md).
*   **Connectivity:** The [Nova Widget](./Nova Widget.md) utilizes MeshSync technology to achieve extended communication range, indicating its participation in a [Mesh Networking](./Mesh Networking.md) network.
*   **Hardware:** The chosen Microcontroller Unit (MCU) for these systems is the [nRF52840](./nRF52840.md).
*   **Power Management:** A key design target for the embedded systems is an 18-month [Battery Life](./Battery Life.md).
