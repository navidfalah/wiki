# Software Releases

## Overview

This page details recent software releases, specifically focusing on MeshSync 0.3.8 by AuroraLabs. This release introduces significant improvements, including fixes for connection stability and an updated communication protocol. It also clarifies hardware compatibility and provides guidance on system scalability.

## Key Details

*   **MeshSync 0.3.8 Release**: AuroraLabs announced the live release of MeshSync version 0.3.8.
    *   **Key Features**:
        *   **Rejoin Fixes**: Addresses issues related to devices rejoining the mesh network.
        *   **MQTT Schema v2**: Implements an updated MQTT communication schema, enhancing data exchange and compatibility.
    *   **Documentation**: Comprehensive documentation for MeshSync 0.3.8 is available on the AuroraLabs wiki.
*   **Node Limitations**:
    *   For beta deployments, a maximum of 6 nodes is recommended for optimal performance and stability.
    *   Development efforts are underway to improve support for up to 8 nodes.
*   **Hardware Compatibility**:
    *   The CR2032 battery type is confirmed as compatible for associated hardware.
*   **Community Engagement**:
    *   AuroraLabs actively engages with its community, including interactions with users like TeaBuddyHQ and gardeningbob.
    *   The team plans to attend Maker Faire, indicating opportunities for direct community interaction and demonstrations.
