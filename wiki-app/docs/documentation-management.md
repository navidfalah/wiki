# Documentation Management

## Overview

Documentation management involves ensuring consistency, accuracy, and timely updates across various forms of documentation, including print materials, digital files, and internal wikis. Challenges often arise when different sources present conflicting information, necessitating clear processes for identifying and resolving these discrepancies. Effective documentation management is crucial for product consistency and customer experience, often impacting shipping decisions.

## Key Details

*   **Consistency Issues**: Discrepancies in product information are a recurring problem, such as the "herbal box copy" stating "5 min" while other sources indicate "7 min."
*   **Multiple Documentation Sources**: Information is spread across various platforms, including:
    *   Print proofs (e.g., herbal box copy v3)
    *   Firmware
    *   Marketing PDFs
    *   Internal wikis
*   **Contradiction Flagging**: A process for flagging and addressing contradictions between different documentation sources is recognized as necessary.
*   **Print Documentation Priority**: Correcting print documentation is prioritized over temporary solutions (like sticker overlays) before product shipment.
*   **Update Processes**: Documentation updates are tied to specific processes, such as a "compile run," after which related folders (e.g., `dummy-test`) need to be updated.
