# Data Privacy

## Overview
Data privacy within the context of the [Aurora Nova Widget](./aurora-nova-widget.md) beta program is primarily addressed through strict [Confidentiality](./confidentiality.md) requirements for Proprietary Information and specific protocols for handling Data Telemetry. Beta Testers are bound by an agreement that outlines how confidential materials should be treated and how user data is managed.

## Key Details

### Confidentiality
Beta testers are obligated to maintain the confidentiality of several key assets related to the Aurora Nova Widget. This includes:
*   **Beta firmware**: Pre-release software versions for the device.
*   **[MeshSync](./meshsync.md) source partial**: Portions of the source code for the MeshSync functionality.
*   **Power budget spreadsheets**: Documentation detailing the device's power consumption and management.

### Data Handling
The handling of data generated by the Aurora Nova Widget is designed with user privacy in mind:
*   **Local Data Storage**: Telemetry data collected by the device remains stored locally by default.
*   **Optional [MQTT](./mqtt.md) Export**: Users have the option to configure an MQTT export for their telemetry data, allowing for user-controlled external transmission if desired. This feature requires explicit User Configuration.

## Related Entities
*   **Aurora Nova Widget**: The device for which data privacy guidelines apply during its beta phase.
*   **Beta Tester**: Individuals participating in the beta program who are subject to the data privacy and confidentiality terms.

## Related Concepts
*   **Confidentiality**: The principle of keeping sensitive information private and restricted from unauthorized disclosure.
*   **Data Telemetry**: The automated communication process by which measurements and other data are collected remotely and transmitted to receiving equipment for monitoring.
*   **Local Data Storage**: The practice of storing data directly on the device itself, rather than transmitting it to external servers by default.
*   **User Configuration**: The ability for users to customize settings and behaviors, such as enabling or disabling data export.
*   **Proprietary Information**: Information that belongs to a company and is considered confidential or trade secret.
