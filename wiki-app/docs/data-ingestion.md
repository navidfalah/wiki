# Data Ingestion

## Overview

Data Ingestion, within the context of an [LLM Wiki pipeline](./llm-wiki-pipeline.md), refers to the systematic process of reading raw data files, extracting relevant topics and entities, and preparing this information for the generation of structured wiki pages. This process is a core function of the "[Heuristic mode](./heuristic-mode.md)" of the [Wiki compiler](./wiki-compiler.md), designed to transform unstructured data into a navigable knowledge base.

## Key Details

### Process
The [Heuristic mode](./heuristic-mode.md) of the [Wiki compiler](./wiki-compiler.md) orchestrates the data ingestion process:
*   It reads all `.txt` and `.md` files from designated raw data directories.
*   Topics are extracted from these files without requiring an LLM API key for this initial phase.
*   The extracted information is then used to generate Docusaurus-compatible wiki pages, which are outputted under `wiki-app/docs/`.
*   A key feature of this process is the automatic generation of cross-links between mentioned entities, enhancing the interconnectedness of the wiki.

### Data Sources
The ingestion process targets various raw data sources, including:
*   Files prefixed with `[SAMPLE]` located under `data/raw/samples/`.
*   Files labeled `[DUMMY TEST DATA]` found under `data/raw/dummy-test/`.
*   Original junk data generated by the `generate_junk_data.py` script.

### Ingestion Challenges and Quirks
The ingestion process is designed to handle various data quality issues and unstructured formats:
*   It tests parser resilience against broken Markdown exports.
*   It addresses the loss of nested content that can occur during forum HTML scrapes.
*   It manages the inclusion of irrelevant "wrong-thread noise" often found in email threads.

### Objective
The overarching goal of data ingestion is to transform a large volume of raw files (e.g., 40+ files) into a rich, interconnected knowledge graph. A critical aspect of this goal is to identify and surface potential contradictions found within the ingested data, such as those related to "battery," "herbal preset," or "read interval."
