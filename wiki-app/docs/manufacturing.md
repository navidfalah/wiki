# Manufacturing

## Overview

This page outlines key considerations and decisions related to the manufacturing process, product design, and feature development, particularly concerning the "widget thing" and its associated systems. It covers material choices, aesthetic goals, naming conventions, and specific feature requests.

## Key Details

*   **Aesthetic Design**: The "widget thing" is intended to have the feel and appearance of garden equipment, specifically to avoid any resemblance to surveillance devices.
*   **Beta Injection Mold Material**: Jonah suggested using PETG for the beta injection mold, contingent on future fundraising efforts.
*   **Mesh Sync Naming**: The name "mesh sync" has been confirmed and should not be renamed again.
*   **Data Export and Dashboard**: Mira has requested MQTT export functionality. Additionally, a CSV dashboard should be available as an optional feature, never mandatory.

## Related Entities

*   **Jonah**: Provided input on material selection for the beta injection mold.
*   **Mira**: Requested specific data export and dashboard features.

## Related Concepts

*   **Beta Injection Mold**: A manufacturing step for early product testing.
*   **PETG**: A type of thermoplastic polyester commonly used in manufacturing for its durability and ease of use.
*   **Aesthetic Design**: The visual and tactile qualities of a product.
*   **Mesh Sync**: A component or system whose naming has been finalized.
*   **MQTT Export**: A feature for exporting data using the Message Queuing Telemetry Transport protocol.
*   **CSV Dashboard**: A user interface displaying data, with an option to export in Comma Separated Values format.

## Contradictions
