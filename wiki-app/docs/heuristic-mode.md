# Heuristic Mode

## Overview

Heuristic Mode is a component of an LLM Wiki pipeline designed to process raw text and Markdown files into a structured wiki. It operates without requiring an LLM API key for topic extraction, focusing on generating Docusaurus-compatible pages and building cross-links between mentioned entities. Its primary goal is to transform a large volume of raw data into a rich knowledge graph, surfacing potential contradictions within the content.

## Key Details

### Functionality
Heuristic Mode performs several core functions:
*   **Input Processing**: Reads all `.txt` and `.md` files located under the `data/raw/` directory.
*   **Topic Extraction**: Extracts topics from the raw content without the need for an LLM API key.
*   **Page Generation**: Generates Docusaurus-compatible wiki pages, placing them in the `wiki-app/docs/` directory.
*   **Cross-linking**: Automatically builds cross-links between mentioned entities, such as [Nova Widget](./nova-widget.md), [TeaBuddy](./teabuddy.md), and [MeshSync](./meshsync.md), to enhance navigability and interconnectedness.

### Input Data Sources
The system processes data from various test data layouts:
*   `data/raw/samples/`: Contains files prefixed with `[SAMPLE]`.
*   `data/raw/dummy-test/`: Contains files labeled `[DUMMY TEST DATA]`.
*   Original junk data generated by the `generate_junk_data.py` script.

### Known Ingest Quirks
The mode is designed to handle various data quality challenges:
*   **Broken Markdown Exports**: Tests the parser's resilience against malformed Markdown.
*   **Forum HTML Scrapes**: Addresses the common issue of losing nested content during the scraping of forum HTML.
*   **Email Threads**: Manages "wrong-thread noise" often found within email conversations.

### Overall Objective
The overarching goal of Heuristic Mode is to process over 40 raw files, transforming them into a comprehensive knowledge graph that also highlights and surfaces contradictions found within the data.
