# نصب نسخهٔ Google Apps Script

این نسخه مستقل است و برای اجرا به Python، Node.js یا سرور جداگانه نیاز ندارد. پوشهٔ `src` کد ماژولار را دارد؛ بستهٔ آمادهٔ `dist/Wissensbau-AppsScript.zip` نصب ساده‌تری دارد.

۱. فایل ZIP را باز کنید. در [Google Apps Script](https://script.google.com/) یک پروژهٔ جدید بسازید.

۲. محتوای فایل `Code.gs` موجود در بسته را جایگزین فایل پیش‌فرض پروژه کنید. این فایل همهٔ بخش‌های سمت سرور را یکجا دارد.

۳. پنج فایل HTML با نام‌های `Index`، `Styles`، `Fonts`، `Translations` و `Client` بسازید و محتوای فایل‌های مربوط را در آن‌ها قرار دهید. داخل ویرایشگر نام را بدون `.html` وارد کنید.

۴. در تنظیمات پروژه، نمایش فایل `appsscript.json` را فعال کنید و محتوای manifest بسته را در آن بگذارید.

۵. در بخش Services، سرویس **Drive API v3** را با نام `Drive` فعال کنید. اگر از پروژهٔ مستقل Google Cloud استفاده می‌کنید، Google Drive API را آنجا هم فعال کنید.

۶. از مسیر **Deploy → New deployment → Web app** انتشار را آماده کنید. اجرای برنامه را روی **User accessing the web app** و دسترسی اولیه را روی **Only myself** بگذارید. این انتخاب برای جدا ماندن اطلاعات هر حساب مهم است.

۷. مجوزهای Google را تأیید کنید و لینک وب‌اپ را باز کنید. با دکمهٔ ساخت فضای کاری، پوشه‌های لازم در Drive ساخته می‌شوند. برنامه فایل‌های اصلی شما را بازنویسی نمی‌کند.

۸. فایل‌های Word، Excel و PowerPoint را آپلود کنید یا لینک فایل‌های Google Docs، Sheets و Slides را وارد کنید. واردکردن لینک، یک کپی در پوشهٔ ورودی می‌سازد؛ همگام‌سازی خودکار با اصل فایل نیست.

۹. گزینهٔ ساخت ویکی را بزنید. در حالت پیش‌فرض، صفحه‌ها از متن منابع ساخته می‌شوند و هیچ مدل هوش مصنوعی فراخوانی نمی‌شود. جست‌وجو و چت، بخش‌های مرتبط منبع را با ارجاع نمایش می‌دهند.

۱۰. اگر تحلیل موضوعی، خلاصه‌نویسی یا پاسخ تولیدی می‌خواهید، در Settings آدرس API سازگار با OpenAI، نام مدل و کلید خودتان را وارد کنید. استفاده از API برای ساخت ویکی و برای چت دو گزینهٔ جداست. کلید در User Properties حساب شما نگهداری می‌شود و داخل فایل‌های عادی Drive قرار نمی‌گیرد.

فایل‌های Google به‌صورت بومی خوانده می‌شوند. DOCX/XLSX/PPTX مستقیماً با JavaScript خوانده می‌شوند؛ برای PDF و قالب‌های قدیمی تلاش می‌شود یک کپی موقت به قالب Google تبدیل شود. کیفیت تبدیل باید با اصل فایل بررسی شود. فایل رمزگذاری‌شده، بعضی قالب‌های Microsoft و محتوای تصویری/صوتی محدودیت دارند؛ فهرست دقیق در `INSTALL-en.md` آمده است.

اگر ساخت طولانی شد، صفحه را باز نگه دارید یا از ادامهٔ ساخت استفاده کنید. گزینهٔ ادامه در پس‌زمینه، یک تریگر زمانی زیر حساب خودتان می‌سازد. محدودیت زمان و سهمیه‌های Google همچنان برقرارند. نسخهٔ قبلی ویکی تا تکمیل نسخهٔ جدید فعال می‌ماند.

فایل ZIP را نمی‌توان مستقیماً داخل ویرایشگر Apps Script آپلود کرد؛ فایل‌ها را طبق مراحل بالا بسازید یا از ابزار رسمی clasp استفاده کنید. پوشهٔ منبع ماژولار و فایل ترکیبی `Code.gs` را هم‌زمان در یک پروژه کپی نکنید.

این کد به‌صورت محلی آزموده شده است؛ هنوز در حساب Google شما نصب یا با API واقعی مدل آزمایش نشده است.
